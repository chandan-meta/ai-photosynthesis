All new authored files live under Assets/Photosynthesis/Art/Upgraded. Textures are outside Resources; only assigned material dependencies are packaged. AI source is retained under Sources/RootEpidermis_AI.png. Other maps and source masks are generated by Tools/GenerateBiologyMaps.py. The custom shaders use URP's native lighting libraries, normal maps and SRP-compatible UnityPerMaterial buffers. Water uses one front-face transparent pass, controlled Fresnel and animated normal sampling, without a new opaque-texture/refraction dependency.

Both neww files were inspected in Blender and through Unity's actual importer. Unity's triangle counts are used above; Blender's polygon count is not an engine triangle count. The initial Blender comparison could not import the old ASCII FBX, so the read-only Unity modelaudit command supplies the authoritative comparison. Nothing in neww is deleted or overwritten. No model replacement or animation retarget is warranted by the inspected candidates.

Clue 02 also keeps its existing opaque soil maps and changes the small quartz-grain finish from glass to rough mineral using those maps. A restrained neutral underground fill replaces the overly warm material illumination; camera/exposure are unchanged. No global greenhouse lighting or post-processing changes accompany this pass.

No Figma canvas or Unity UI changes are needed because this brief locks the approved interface. The existing Figma-derived Docs/UI_SPEC.md remains the interface record.
