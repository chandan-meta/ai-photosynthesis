# Photosynthesis — The Hidden Food Factory · Unity architecture (Scene 2 onward)

Unity 6000.3.0f1 · URP 17.3 (PC_RPAsset) · Input System only (`activeInputHandler: 1`) · UI Toolkit runtime UI.
Scene: `Assets/Photosynthesis/Scenes/Scene02_BotanicalChamber.unity`, generated by **Photosynthesis ▸ Build Scene**
(`Scripts/Editor/PhotosynthesisBuild.cs`). Scene 1 is out of scope and never touched.

## Composition
`Module` (Core/Module.cs) is the composition root. It owns every subsystem (no runtime scene searches):

| Field | Type | Where it lives |
|---|---|---|
| `chamber` | `Chamber` | scene object (dome + vegetation placed by the editor builder) |
| `cam` | `CameraDirector` | Main Camera |
| `plant` | `HeroPlant` | created at runtime under `chamber.PlantAnchor` |
| `curio` | `Curio` | created at runtime |
| `leafSurface, soil, xylem, tissue, cell, chloroplast, interior` | `MicroWorld` subclasses | created at runtime, far away (±2000 units), hidden until shown. `interior` = `LeafInteriorWorld`, the Scene 3 prologue vista built from the client model `Resources/Models/LeafInside.fbx` |
| `hud, audioDirector, dialogue, story, ai, debugTools` | components on the Module object | |
| `clues` | `ClueBoard` | clue order is enforced here |
| `assessment` | `Assessment` | Q1–Q20 bank + adaptive logic |

## Flow
`Story` (Story/Story.cs) plays `Beat`s in order (Types.cs). Each beat is a coroutine that can cold-start: `Prepare(beat)`
resets visuals, clue board, places Curio, and the beat calls `GoTo(place)` / `Ensure*()` for whatever it needs.
Progression waits on: dialogue (`Dialogue.Say(id)` → VO clip length or reading time), learner input (clue selection,
buttons, picks), world coroutines (e.g. `xylem.Ride`). Debug jumps = `story.Run(beat)`.
`Play` runs Scene2Start … FinalPlant; FinalPlant ends in `Finale()` ("THIS IS PHOTOSYNTHESIS", fade, end menu) which re-enters `Run` for
Replay (Scene2Start) or Review (FreeExplore). Beats after FinalPlant (Assessment, Complete, FreeExplore) only run when jumped to, or from Review.

Lines: `Resources/curio_lines.txt` (`id|text`). Voice clips: `Resources/VO/<id>.wav` (generated, see Tools/GenerateVO.py).
Dynamic replies: `Dialogue.SayText` splits the text into sentences, loads `Resources/VO/kb/<Dialogue.KbKey(sentence)>` for each and joins
them into one clip; any missing sentence → the device voice for the whole reply. `GenerateVO.py --kb` uses the same key and split.
Question lines use ids `q_<QID>_lead`, `q_<QID>_ok`, `q_<QID>_no`.

## Rendering rules
* Materials: never `Shader.Find` or keyword changes at runtime. Use `Fx.Mat(kind, color, emission)` / `Fx.Shared(...)`,
  which clone template materials from `Resources/PhotosynthesisMaterials` (`MatLib`) so builds keep every variant.
  Kinds: Lit, LitEmissive, LitTransparent, Glass, Unlit, UnlitTransparent, Additive, Leaf (double-sided lit),
  ParticleAdditive, ParticleAlpha. Emission is HDR: multiply colour by 2–6 for bloom (bloom threshold 1.0).
  `MatLib.rim` (shader `Photosynthesis/MoleculeRim`, `Shaders/MoleculeRim.shader`): an additive fresnel edge light. `Fx.Molecule` adds it as
  a second material on every atom (`Fx.Rim(colour)`, a lighter tint of the atom, LDR so it never blooms). Code that swaps atom materials
  must swap the whole `sharedMaterials` set (see `LeafSurfaceWorld.SetDim`).
* Post: Bloom, ACES, colour adjustments, vignette, Bokeh depth of field (Global Volume). The DoF is off by default; `CameraDirector`
  switches it on only during scripted shots (Blend / Arc / Ride / Push, High quality tier, not with Reduce motion), focused on the shot's
  subject, so orbit views, text, selectable structures and molecules stay sharp. Ambient is Trilight (no baking).
* Micro worlds set their own `RenderSettings` fog/ambient in `ApplyMood()`; `Chamber.SetVisible(true)` restores the chamber mood.
* Colours: `Palette` (Types.cs) == Figma tokens.

## Dr. Curio's scarf
The robot is built in code (`Curio.Build`); the one imported piece is the green scarf from the user's `charcter/dr.blend`:
`Tools/Curio/scarf.py` → `Resources/Characters/Curio_ScarfMesh.obj` (rig space) + `Curio_Scarf.png` (baked fabric). Re-run the script after
the user edits the scarf in Blender.

## Input
Input System only (`UnityEngine.InputSystem`): `Mouse.current`, `Touchscreen.current.primaryTouch` (the finger is the pointer while
it is down: drag = rotate, tap = click; pan stays on the mouse), `Keyboard.current`. The camera exposes `Clicked(screenPos)` (click
without drag) and `UserZoomed(delta)`. UI blocks 3D input via `Hud.PointerOverUI`.

## Testing
* Compile without Unity: `bash Tools/Compile/check.sh` (Runtime + Editor projects reference Unity's DLLs).
* Player command line: `-beat <Beat>`, `-autoplay [-wrongfirst]`, `-shots <dir>`, `-quitafter <s>` (DebugTools.cs).
* F1 in development builds: debug panel (jump to any beat, skip VO, time scale, unlock clues, FPS/draw-call stats).
